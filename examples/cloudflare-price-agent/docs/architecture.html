当前：Agents SDK 和工具执行代码都在 Cloudflare；Chrome 在 Browser Run。本地 Node 只做请求转发。

DeepSeek 负责返回下一步工具调用；我们写的 Agent 循环负责真正执行。这个 Cloudflare demo 使用 Cloudflare 的 SDK，未接入之前 Docker demo 的 OpenMuse 电脑控制 SDK。

橙色高亮可逐步查看一次工具调用。Agent 代码、模型推理服务、Chrome 进程是三个不同的运行位置。

三个 SDK / 模块，各自负责什么？

Cloudflare Agents SDK

有状态运行框架

PriceAgent 继承 Agent；提供持久状态、SQLite、RPC 与调度。对话循环和工具定义由本项目代码实现。

@cloudflare/puppeteer

浏览器控制客户端

控制代码运行在 DO；通过 BROWSER binding 启动/连接远程 Chrome，执行导航、点击、DOM 读取与截图。

之前的 OpenMuse 电脑 SDK

一次工具调用到底发生了什么？

用户：“搜索某商品价格” → DO 把历史消息和工具清单发给 DeepSeek → 模型返回 browser_search({query: ...}) → DO 校验并执行 → Puppeteer 操作云端 Chrome → 返回页面正文和元素 ref → DO 把结果作为 tool 消息交回模型 → 模型继续操作或回答。

模型拿到的是网页观察结果和允许的工具定义。模型不会直接登录 Worker、获得浏览器 CDP 连接或执行我们的 TypeScript 代码。

截图在工具操作后更新；Live View 是另一条实时链路。只有截图更新，不能据此认定实时画面连接正常。

模型工具允许

搜索、打开 HTTP(S) 网页、读取网页可见正文、点击、普通文本输入、Enter / Tab / Escape、滚动，以及记录网页价格证据。

模型工具未提供

读取本机/服务器文件、列目录、Shell / 终端命令、安装软件、Linux 桌面控制、任意 JavaScript 执行、文件上传下载 API。

读取网页内容是浏览器使用的一部分；Cookie / localStorage 的保存是内部会话管理，不是给 Agent 开放通用文件系统。

当前权限边界落实在哪里？

工具注册：src/core.ts 只向模型发送 7 个浏览器动作和 1 个证据工具。

工具分发：DemoBrowser.action() 在启动浏览器前拒绝未注册工具、文件协议及无效导航。

页面操作：校验当前页面网址；拒绝文件输入框、显式 download 链接和非网页协议链接。

请求拦截：HTTP(S) 走公开域名检查；data/blob 只作为内嵌资源；拦截到的本地/内部协议请求被拒绝。

后端：没有文件或命令 API，未绑定 Sandbox / Containers，也没有连接 Docker。

以上是应用的 Agent 工具策略。人工 Live View 仍是远程浏览器交互；请求拦截不是操作系统隔离或 DNS 固定，也不能证明所有浏览器自主下载都被阻止。

运行事实与限制

架构来自源码与已部署入口，不代表本地代理承担了模型推理或浏览器操作。

目前是单 owner 私有 demo：一个访问口令对应一个 DO，多对话存于其 SQLite。没有实现 2000 用户的独立租户鉴权与调度。

本次云端模型拒绝了读取服务器文件的请求，且没有启动 Chrome；随后普通网页浏览在创建浏览器时仍返回 HTTP 429。权限单元测试 28 项通过，真实浏览器的新策略行为和完整 UI 视觉验收仍未完成。

实时展示的是云端 Chrome 页面，不是完整 Linux 桌面。
